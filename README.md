# NTFS for Mac Community

一个免费、简洁的 Mac NTFS 写入工具。SwiftUI 原生界面，中英双语，无订阅、广告或在线激活。

**社区预览版 v0.2.0-preview.1**：[安装包与对应第三方源码](https://github.com/ebrx/ntfs-for-mac-releases/releases/tag/v0.2.0-preview.1)。免费领取、永久离线激活；请先阅读适配范围和安装说明。

## 使用方式

1. 从 Releases 下载测试包，阅读安装说明及对应系统范围。
2. 安装应用及官方 macFUSE 依赖，在系统设置中完成首次确认。
3. 私信作者免费领取授权码，在应用中粘贴激活；授权码离线验证，永久有效，后续版本沿用同一验证公钥时仍有效。
4. 首次为自己的 NTFS 磁盘选择自动写入；应用运行时再次插入可自动处理，在 Finder 中操作文件。

授权码不绑定 Apple ID、账号或设备，不收费。它可以被转发，因此是方便发放的免费领取机制，不是强防复制 DRM。旧本机版没有激活限制。

当前验证环境：Apple Silicon、macOS 26.6.2 / 25G83、macFUSE 5.4.0。社区版已通过独立辅助服务自建 NTFS 镜像读写、重启恢复、真正只读及正常弹出验收；授权签名、篡改拒绝和辅助服务授权门槛已验证。PKG 与 ZIP 的实际解包内容及应用签名一致性已检查。

## 实现机制

![磁盘写入机制](images/disk-flow.svg)

主应用提供磁盘识别、挂载管理、自动写入、Finder 入口及界面；NTFS 读写使用 NTFS-3G，通过 macFUSE 的 FSKit 后端接入 macOS。认证辅助服务核对调用者、磁盘身份和引擎，持有设备权限；写入引擎以普通用户身份工作。只读使用 Apple NTFS，退出和弹出等待写入正常停止。不提供格式化、修复、强制写入或 BitLocker 解锁。

![离线授权机制](images/activation-flow.svg)

授权码由作者在本机签发，应用内只存公钥。没有联网验证、有效期或云端开关；系统适配失败和授权过期是不同问题。系统更新可能需要新的兼容版本，授权永久有效不代表任何未来系统都已获得支持，也不承诺无限期维护。
